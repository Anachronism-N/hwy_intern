# 双人求职研究库 · GitHub Pages

本仓库仅发布审核后的完整静态界面及公开示例，保留岗位检索、收藏、对比、跟进、企业研究、方向地图、双人规划、收入计算、行动清单和导出功能。

## 启用免费 Pages

仓库 Settings → Pages → Build and deployment：Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，点击 Save。
GitHub 返回部署地址后，以 Settings → Pages 中实际显示的网址为准。

## 完整资料只在本机导入

网页默认提供公开示例。点击“载入完整资料 JSON”，选择本人保管的完整资料 JSON，才能使用原站完整资料与个人化分析。

**不要提交 PRIVATE-LOCAL-DATA.json、PRIVATE-LOCAL-DATA.zip、个人简历、私有原表、.env、密码、Token 或任何密钥。公开仓库中的文件可被任何人读取。**

默认不记住完整资料，刷新需重新导入；勾选记住后仅存在本设备浏览器。收藏、回答和行动进度同样仅在本机，不会跨设备同步。共享设备使用完请清除本机资料。此方式不是账户认证或加密。

## 数据与验证边界

软件发布准备于2026-11-21；公开示例沿用2026-11-18信息快照，未重新核验招聘开放状态。历史记录不是当前在招承诺。

已完成构建、发布文件哈希及资料关联检查；9项本机导入单元测试通过（模拟File/DOM/IndexedDB）。桌面公开示例已测搜索、收藏、双岗位对比、收入计算及回答保存。真实浏览器全量导入、手机布局与大陆无VPN线路未完成验证。

本站为纯静态工具，无后端账号或云端资料数据库。腾讯云上的旧站不会因本仓库提交而自动变化。
